# ETA-Motion: Efficient Topology-Agnostic Motion Diffusion via Sparse Joint Learning

### WACV 2027

**Seoyoung Hwang<sup>1,2</sup> and Tae-Kyun Kim<sup>1</sup>**  
<sup>1</sup> KAIST · <sup>2</sup> Samsung Electronics

## 🏠 [Project Page](https://sy-hwang.github.io/eta-motion-page/) | Paper (Coming soon)

![ETA-Motion teaser](https://raw.githubusercontent.com/sy-hwang/eta-motion-page/main/site/assets/images/teaser.webp)

Official implementation of **ETA-Motion**, accepted to **WACV 2027**.

ETA-Motion is a text-conditioned motion diffusion framework for characters with diverse skeletal topologies. By learning from sparse joint subsets with semantic joint embeddings, it supports full-skeleton motion generation while improving efficiency and generalization across characters.
